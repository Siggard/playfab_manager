# PlayFab Bundle Editor

Визуальный редактор для управления каталогом PlayFab — бандлами, сущностями и их связями.

## Возможности

- Загрузка JSON-каталога из PlayFab
- Drag & Drop управление сущностями в бандлах
- Фильтрация и поиск по типам и названиям
- Создание и редактирование сущностей
- Автосохранение в localStorage каждые 30 секунд
- Экспорт обратно в JSON для загрузки в PlayFab
- Прямой Pull / Push каталога из/в PlayFab через Cloudflare Worker (см. ниже)
- Картинки сохраняются прямо в выбранную папку проекта на диске

## Запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev
```

Откроется на http://localhost:5173

## Использование

1. **Загрузка данных**: Нажми "Load JSON" и выбери файл каталога из PlayFab (формат `{ CatalogVersion, Catalog: [...] }`)
2. **Работа с бандлами**: Перетаскивай сущности из пула в бандлы и между бандлами
3. **Редактирование**: Клик на сущность открывает редактор
4. **Создание**: Кнопка "+" для создания новых сущностей
5. **Экспорт**: "Export JSON" для скачивания обновлённого каталога

## Структура данных

Редактор работает с JSON-каталогом PlayFab:
```json
{
  "CatalogVersion": "Main",
  "Catalog": [
    {
      "ItemId": "p_1",
      "ItemClass": "player",
      "DisplayName": "Player Name",
      "Bundle": null,
      ...
    },
    {
      "ItemId": "bundle_1",
      "ItemClass": "starter_pack",
      "Bundle": {
        "BundledItems": ["p_1", "p_2"]
      },
      ...
    }
  ]
}
```

## Автосохранение

- Автоматическое сохранение в браузер каждые 30 секунд
- При открытии предложит восстановить несохранённые данные
- Кнопка ручного сохранения в header

## Первая настройка (для нового пользователя)

После того как тебе скинули ссылку на редактор (GitHub Pages), нужно сделать **два шага**, потом редактором можно пользоваться полноценно.

### Требование к браузеру

**Chrome или Edge** (Safari подойдёт свежий). В Firefox не работает прямая запись картинок в папку — там можно открывать каталог и редактировать, но картинки не будут складываться на диск.

### Шаг 1 — указать папку для картинок

Картинки пишутся напрямую в папку твоего локального клона игрового проекта. У тебя и у напарника эта папка может быть в разных местах (`C:\Work\FCM_2\images\content` у одного, что-то другое у другого) — в каталоге хранится только относительный путь, поэтому формат остаётся переносимым.

1. Открой редактор по ссылке.
2. Кликни на иконку настроек (`[=]`) справа в шапке.
3. Перейди на вкладку **Data**.
4. В секции **Image Folder** жми **Pick Folder**.
5. В системном диалоге выбери папку с картинками твоего клона проекта (у нас договорились — `<твой_клон>/images/content`).
6. Браузер спросит подтверждение доступа на чтение/запись — нажми **Allow**.

Готово: статус должен показать `Folder: content` и `access granted`. После рестарта браузера один раз нужно будет нажать **Re-grant Access** в той же секции — браузер из соображений безопасности раз в сессию переспрашивает разрешение.

> **Важно**: картинки в каталог как ссылка на PlayFab не уходят. Путь к ним кладётся в `CustomData.imagePath` (например `debuff_player/debuff_player_3.png`), а сами файлы синхронизируются между вами через **git** игрового проекта — я добавил картинку, закоммитил, ты запулил, у тебя она появилась на диске и подхватилась редактором.

### Шаг 2 — настроить синхронизацию с PlayFab

Прямой Pull/Push в PlayFab идёт через наш Cloudflare Worker (он держит секретный ключ PlayFab у себя; в браузер он не попадает).

1. Те же настройки — вкладка **PlayFab**.
2. Поля:
   - **Worker URL** — уже подставлен дефолтом, ничего трогать не надо.
   - **Editor Password** — общий пароль (попроси у напарника лично; в README его нет специально).
   - **Catalog Version** — `Main`, тоже дефолт.
3. Нажми **Test Connection** — должна появиться зелёная надпись `Worker reachable`. Если `Unauthorized` — пароль неправильный.

После этого в шапке редактора оживут две кнопки:

- **Pull** — забрать актуальный каталог из PlayFab в редактор (заменит то, что сейчас открыто, спросит подтверждение).
- **Push** — залить текущее состояние редактора обратно в PlayFab. **Полная замена каталога** в PlayFab — то, чего нет в редакторе на момент Push, удалится в PlayFab. В подтверждении показывается количество сущностей, чтобы можно было отменить, если число подозрительное.

Типичный воркфлоу: **Pull → правишь → Push**. Картинки между Pull/Push к PlayFab отношения не имеют — они едут через git.

## Tech Stack

- Vue 3 (Composition API)
- Vite
- vuedraggable (drag & drop)
- IndexedDB / localStorage (автосохранение, хэндл папки)
- File System Access API (запись картинок на диск)
- Cloudflare Worker (прокси к PlayFab Admin API, см. `worker/README.md`)
